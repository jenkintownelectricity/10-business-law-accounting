# Domain Objects

Typed domain models for the **10-Business-Law-Accounting** sovereign domain monorepo.

## Purpose

This package provides the canonical TypeScript interfaces for every first-class object in the system. All kernels (Business, Law, Accounting), the Commercial Orchestrator, the Voice-Assist Layer, and the Language Intelligence Layer consume these types.

## Object Catalog

### Core Case-Management Objects

| Module | Primary Type | Description |
|--------|-------------|-------------|
| `matter.ts` | `Matter` | Central case-management record tying contracts, obligations, events, evidence, and decisions together across all three kernels. |
| `contract.ts` | `Contract` | Full contract model with parties, terms, obligations, financial value, risk assessment, and evidence references. |
| `obligation.ts` | `Obligation` | Legal, financial, and operational obligations arising from contracts, matters, or regulations. |
| `invoice.ts` | `Invoice` | Invoice with vendor/client, line items, tax, payment status, ledger classification, and accounting period. |
| `accountingEvent.ts` | `AccountingEvent` | Financial event with classification, period, tax implications, and reconciliation status. |
| `entity.ts` | `Entity` | Client, vendor, counterparty, or other business entity with contact info, financials, and relationships. |
| `deadline.ts` | `Deadline` | Time-sensitive deadline with source, reminder schedule, status, and criticality. |
| `evidence.ts` | `Evidence` | Document, recording, or artifact with fingerprint, trust level, chain of custody, and linked matters/decisions. |

### Decision and Assessment Objects

| Module | Primary Type | Description |
|--------|-------------|-------------|
| `decisionBundle.ts` | `CommercialDecisionBundle` | Cross-domain decision artifact assembled by the Commercial Orchestrator from kernel assessments. |

### Voice and Language Objects

| Module | Primary Type | Description |
|--------|-------------|-------------|
| `transcriptEnvelope.ts` | `TranscriptEnvelope` | Voice-to-text transcript with speaker attribution, confidence scores, and kernel routing. |
| `spokenCommand.ts` | `SpokenCommandCandidate` | Parsed voice command candidate requiring practitioner review before execution. |
| `spokenNote.ts` | `SpokenNoteEnvelope` | Dictated note with structured draft for practitioner editing. |
| `listeningSession.ts` | `ListeningSession` | Iron Ear session capturing meetings/calls with obligation and deadline extraction. |
| `languagePacket.ts` | `LanguageNormalizationPacket` | Language normalization output with terminology alignment and disambiguation. |
| `advisoryPacket.ts` | `AdvisoryIntakePacket` | Intake packet from voice/language/listening. Always UNTRUSTED until reviewed. |
| `routedCandidate.ts` | `RoutedKernelCandidate` | Candidate routed to a specific kernel, requiring practitioner review. |
| `voiceSessionState.ts` | `VoiceSessionState` | Real-time state of an active voice session. |

## Trust Model

All objects that originate from automated or advisory sources carry a `trust_level` field:

- **`TRUSTED`** — Created or explicitly approved by a practitioner.
- **`UNTRUSTED`** — Generated by an automated process; requires practitioner review before becoming sovereign.

Voice and language objects enforce `review_required: true` and `trust_level: 'UNTRUSTED'` by design. No advisory input becomes a sovereign record without practitioner approval.

## Usage

```typescript
import type { Matter, Contract, Obligation, CommercialDecisionBundle } from '@10-bla/domain-objects';
```
