# Seeds

Starter scenarios for the Business Law Accounting Domain OS.

These seed scenarios demonstrate cross-domain workflows and can be used for testing, onboarding, and validation of kernel interactions.

## Scenarios

- **contract-review-scenario.json** — Software licensing agreement review (Law + Business)
- **invoice-processing-scenario.json** — Vendor invoice processing (Accounting + Business)
- **commercial-matter-scenario.json** — Cross-domain acquisition assessment (Business + Law + Accounting)
- **spoken-contract-review-note.json** — Dictated contract review note (Voice + Law)
- **meeting-transcript-scenario.json** — Meeting with obligation candidates (Voice + Law + Business)
- **voice-created-task-draft.json** — Voice-created follow-up task (Voice + Business)

## Usage

Each scenario file contains a self-contained payload that can be submitted to the Commercial Orchestrator for routing and processing.
