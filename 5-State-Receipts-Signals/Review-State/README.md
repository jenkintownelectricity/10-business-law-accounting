# Review-State

Review state management for items requiring practitioner review.

## Purpose

Tracks review queue items including matters, contracts, obligations, decision bundles, transcripts, spoken notes, advisory packets, and listening sessions. Manages the lifecycle of items through the review process from pending to approved/rejected/deferred.

## Features

- Add items to the review queue with source and trust level tracking
- Transition items through review states
- Query by status, type, priority, and assignee
- Track review notes and timestamps
