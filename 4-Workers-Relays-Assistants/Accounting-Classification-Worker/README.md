# Accounting-Classification-Worker

Classifies financial events and invoices.

## Purpose

Receives accounting events and invoices, classifies them into ledger categories, assigns accounting periods, evaluates tax implications, and checks reconciliation status.

## Behavior

- Receives accounting events and invoices
- Classifies into appropriate ledger categories
- Assigns accounting periods
- Evaluates tax implications
- Checks reconciliation status
- Emits domain receipts for all classification operations
