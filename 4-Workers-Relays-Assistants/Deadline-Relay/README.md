# Deadline-Relay

Monitors and relays deadline signals.

## Purpose

Scans active obligations, contracts, and matters for upcoming deadlines. Emits deadline signals with priority and criticality. Supports configurable reminder windows.

## Behavior

- Scans active obligations for approaching deadlines
- Scans contracts for expiration and renewal dates
- Scans matters for filing and response deadlines
- Emits deadline signals with priority and criticality levels
- Supports configurable reminder windows (e.g., 30d, 7d, 1d)
- Emits domain receipts for all deadline signals
