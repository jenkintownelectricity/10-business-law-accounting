# Obligation-Extraction-Worker

Extracts and tracks obligations from contracts and matters.

## Purpose

Parses contracts for obligation clauses, creates typed Obligation records, sets deadline tracking, and evaluates legal constraints.

## Behavior

- Parses contract text for obligation clauses
- Creates typed Obligation records with deadlines
- Sets up deadline tracking for each obligation
- Evaluates legal constraints against obligations
- Emits domain receipts for all extraction operations
