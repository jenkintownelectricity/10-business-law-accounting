# Matter-Orchestration-Worker

Orchestrates cross-domain matter processing.

## Purpose

Manages matter lifecycle across kernels. Collects kernel assessments, assembles decision bundles, tracks follow-up actions, and manages state transitions.

## Behavior

- Manages matter lifecycle across Business, Law, and Accounting kernels
- Collects and correlates kernel assessments
- Assembles decision bundles from kernel outputs
- Tracks follow-up actions and deadlines
- Manages state transitions with full audit trail
- Emits domain receipts for all orchestration operations
